## Labrador Greeter
A minimal login greeter written in C. I named it "Labrador-Greeter" because it's as friendly and loyal as a Labrador.

## Installation process
You need to compile it first. Make sure you're at the root of the repository and you have gcc installed.
```bash
./compile.sh
```
Then you install it.
```bash
./install.sh
```
If you encounter any issues, report them via the repository on GitHub.

## Reversing the installation process
Run the removal script at the root of this repository.
```bash
./uninstall.sh
```
