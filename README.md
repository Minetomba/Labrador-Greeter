## Installation process
First, you will need to run a system update.
```bash
sudo pacman -Syyu
```
Then you need to compile it. Make sure you're at the root of the repository.
```bash
./compile.sh
```
Then you install it.
```bash
./install.sh
```
If you encounter any issues, report them via the repository on GitHub.

## Reversing the installation process
Run the removal script at the root of this repository.
```bash
./uninstall.sh
```
